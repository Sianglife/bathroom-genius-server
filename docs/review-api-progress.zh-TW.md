# 階段 3：評論 API 進度

日期：2026-11-09。PR1 程式實作與自動測試已完成；手動測試全部尚未完成。

## PR1：評論驗證與公開契約

- 新評論的公開名稱取自已驗證 session 的帳號名稱，保存建立當時的名稱；不再接受 authorName 輸入。這是寫入契約變更，其他呼叫端必須移除該欄位。
- isAnonymous 選填，建立時預設 false；true 時公開顯示「匿名使用者」，保留後端作者關聯。改回 false 時恢復保存的名稱。null 不是合法匿名設定。
- comment 去除頭尾空白，依 JavaScript UTF-16 長度限制 1000；cleanScore／convenienceScore 可用 null 清除。新增及更新後至少保留一項評分或非空白文字；衛生紙觀察不算有效內容。
- PATCH 驗證合併後內容；以內部 revision 比對更新，遇到競爭回 409，呼叫端須重新讀取，不應盲目重送。舊文件缺少 revision 時可直接更新，不需批次遷移。
- 公開清單、新增與更新回應提供 canEdit。訪客為 false，作者與管理員為 true；舊匿名評論僅管理員為 true。回應不含 ownerId、userId、revision。
- 公開讀取以可選 session 辨識權限；過期 session 仍能讀取，資料庫等基礎設施錯誤不吞掉。回應使用 private, no-store 與 Vary: Cookie，避免共用快取混用權限。
- 保留舊評論名稱及資料，不使用舊 userId 認領。既有超長評論仍可讀取，修改時須符合新規則。
- 共用型別與 Swagger 已同步；評論表單、我的評論頁及前端串接均屬階段 5。
