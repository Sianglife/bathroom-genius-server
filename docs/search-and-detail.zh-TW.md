## 搜尋行為

未定位時載入廁所目錄，不顯示距離，也不宣稱距離排序。使用者點「使用目前位置」才呼叫瀏覽器定位；沒有背景定位追蹤。

定位成功後使用 `/api/toilets/nearby`，預設 1 公里、每頁 10 筆；半徑可改為 500 公尺或 3 公里。網站預設不限制評分；設定最低分時仍顯示未評分資料。衛生紙與無障礙依有／無篩選，未知值不當成沒有；標籤符合任一項即可，使用目前資料庫原始大小寫。

定位拒絕、逾時或瀏覽器不支援時，仍可使用文字搜尋。查無結果時提供使用者主動擴大範圍與清除篩選。查詢失敗保留上次成功結果並標示；重試會使用當前條件。切換查詢會中止舊請求並忽略過時回應。

篩選條件放進 URL，精確座標只用於 API 查詢及當前瀏覽器分頁的 sessionStorage，不進入分享網址。搜尋結果、位置、已載入頁次與捲動位置可在同一分頁返回時恢復；快取超過 30 分鐘不再採用。sessionStorage 停用或容量不足時仍可搜尋，但不保證重新載入後恢復結果。

「清除位置」會移除儲存的位置，且忽略尚未完成的舊定位回呼。恢復的結果會顯示提示，使用者可按搜尋更新資料。

## API 契約變更

沿用端點，不新增 `/nearby-page`：

```text
GET /api/toilets/nearby?lat=25.033&lng=121.565&radius=1000&page=1&limit=10
```

附近回應由原本陣列改為：

```json
{
  "data": [],
  "total": 0,
  "page": 1,
  "limit": 10,
  "hasMore": false
}
```

- 支援 search、minCleanScore、minConvenienceScore、hasToiletPaper、isAccessible、tags。
- search 上限 200 字，採文字比對，特殊字元不當作正規表示式。
- 半徑上限 10 公里、每頁上限 100 筆、page 為大於等於 1 的整數。
- total 以相同位置、半徑及篩選條件計算。距離由近到遠，同距離依 `_id` 排序；超過最後一頁回傳空 data，保留 total。
- 既有目錄 `/api/toilets` 保留 `{ data, total, page, limit }` 格式，增加固定 ID 排序。
- Bot 使用相同 service，固定 page=1、limit=5、半徑 1 公里、最低兩項評分各 3 分，從 data 讀取推薦結果。
- 這是回應契約變更，部署時須同步更新後端及 Bot；若有其他直接讀取舊陣列的呼叫端，也須改讀 data。

## 詳情與導航

設施缺值顯示「未知」，缺評分顯示「尚無評分」，缺開放時間不推定正在營業。文字資料以 textContent 顯示，評論與備註不作 HTML 執行。

導航使用經驗證的 GeoJSON 座標產生 Google Maps walking URL；直線距離不作為步行距離或時間。座標不完整時顯示說明，其餘資訊仍可閱讀。

評論使用既有公開分頁 API，每次 5 則；載入失敗可重試，廁所資訊及導航仍可操作。日期以臺灣時間顯示。地圖相關功能本次提供導航連結；靜態地圖縮圖仍為選配項目。

## 搜尋模式調整（2026-11-08）

- 「使用目前位置」與「手動輸入」為互斥模式，透過文字連結切換；GPS 模式的定位按鈕旁顯示「手動輸入」，手動模式隱藏定位按鈕，連結改為「使用目前位置」。首頁預設嘗試定位；不支援、拒絕、逾時或無效座標時自動切到手動模式。
- 定位模式隱藏並停用名稱／地址欄位，切換定位時清除關鍵字；手動模式清除座標、隱藏並停用半徑，只依名稱／地址及設施條件查詢。手動輸入目前仍是名稱／地址文字搜尋，不會將地址轉成座標。
- 分享的文字搜尋網址與返回列表的快取保留原搜尋模式，不強制重新定位。切換模式會取消舊查詢並忽略待完成的定位回呼。
- 結果呈現集中於 `.search-result-view`（目前 `data-view="list"`），與定位／手動輸入控制分離。後續可在此嵌入地圖，沿用查詢、篩選與狀態管理；地圖尚未實作，標記完整性及地圖視窗查詢需另行定義，不能只將已載入的分頁資料視為全部結果。
- 原階段 4 手動驗收已由使用者確認通過；本次搜尋模式調整需另行手動驗收。


## 搜尋同字正規化

- 同字清單以 crawler 的 `equivalent_characters.json` 為主，每組第一個字為標準字，目前為 `["臺", "台"]`；不額外推測其他異體字。
- crawler 的 `clean_data.py` 在名稱、地址清理時統一使用此表。後端一般搜尋與附近搜尋共用同字處理，先正規化為「臺」，也能比對尚未清理的「台」字資料；不修改顯示內容。
- 修改 crawler 清單後，在 server 執行 `python scripts/sync-equivalent-characters.py`；以 `python scripts/sync-equivalent-characters.py --check` 確認同步。server 保留產生檔，部署時無須依賴 crawler 目錄。
- 本次未對實際資料庫執行清理；重新清理可能影響名稱與合併分組，需先審查 crawler 的預覽。
